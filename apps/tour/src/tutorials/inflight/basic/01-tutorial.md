## Preflight - Wing's default execution phase

Let's begin with preflight code.

**Reminder:** This is code that runs once, at compile time, to generate the cloud infrastructure configuration of your app.

Take a look at the editor to the right. It contains preflight code that sets up a storage bucket. A bucket is can store objects (such as files) in the cloud under a specified key.

> **In Wing, preflight is the default execution phase, so we don't need any special annotation for it.**

When the code is compiled to a specific target (cloud provider) the `cloud.Bucket` resource is substituted by an implementation for that target. E.g., an S3 Bucket when compiling to AWS.
