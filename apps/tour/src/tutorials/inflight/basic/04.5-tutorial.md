# Inflight - Compilation artifacts

You can see the JavaScript code that is generated when compiling our inflight code by going to the **AWS/Terraform** compilation target window and looking in the ***Assets*** section (below the Resources one).

Click the **"inflight1.js"** file. The "handle" method is the one that will be executed when the cloud.Function is invoked.

Now look at the **Resources** section above the Assets. 

The `cloud.Function` that we defined in the preflight code is there and it is implemented by a Lambda (see the "Lambda" it contains). 

The Lambda needs to be able to run the JavaScript code when it is invoked. So when creating of the configuration of the `cloud.Function` we need to define a bucket that will contain the code that will run when the function is invoked. 

This bucket is the **Default** resource that is implemented with the **S3** it contains. The file with the code that is uploaded to it is the **S3 Object** under the **cloud.Function** resource.

<br/>
We've seen how to define a cloud.Function in preflight and give it inflight code to run whenever it is invoked.
