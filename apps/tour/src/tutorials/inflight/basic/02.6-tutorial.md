# Preflight - methods with specific behavior

You can use all the tools of the Wing programming language to write preflight code. This includes methods, classes, modules, control flow statements (e.g. if, for, while), etc.

However, there are some global methods that have special behavior when used in preflight code. 

### Log()

Adding a log() statement to your preflight code will result in Wing printing the string to the console during compilation.

Copy this code to the editor:
```wing
log("7 * 6 = ${7 * 6}");
```
Then check out the ***Console*** tab on the bottom right to see the result.

### assert()

assert() statements will be evaluated during preflight, and will cause compilation to fail if the assertion fails.

Copy this code to the editor:
```wing
assert(2 + 2 == 5);
```

Then check out the ***Console*** tab on the bottom right to see the result.
