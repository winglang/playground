## Preflight - Hello world

The below code pre-populates our bucket during deployment with a file containing a "Hello World!" text.

Please copy it to the editor in line 5:
```wing
bucket.addObject("hello.txt", "Hello World!");
```

Notice how the **AWS/Terraform** compilation target window has changed again. 

Check out the **"S3 Object"** that was added to the **cloud.Bucket** resource to see details.

Now switch to the **Simulator tab** and click on the **cloud.Bucket**. You should see the "hello.txt" file in the right hand side panel.

> **Although our code uploads a file to a bucket, this is still preflight code that runs only once at compile time. So the file is pre-populated in the bucket during deployment, not when the app is running.**
