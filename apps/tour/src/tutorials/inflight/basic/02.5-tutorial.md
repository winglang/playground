## Preflight - Hello world

The code below populates our bucket during deployment with an object containing a the text `Hello World!`.

Add it in line 5:

```wing
bucket.addObject("hello.txt", "Hello World!");
```

Notice how the **AWS/Terraform** compilation target window has changed again. 

You should see an **"S3 Object"** resource added. This Terraform resource represents the `hello.txt` object.

Now switch to the **Simulator** and click on the **cloud.Bucket**. You should see the `hello.txt` file in the right hand side panel.

> **Although our code uploads an object to the bucket, this is still preflight code that runs only once at compile time. So the file is will be populated in the bucket during deployment, not when the app is running.**
