## Preflight - Compilation artifacts

When compiling preflight code the Wing compiler produces configuration files that define the application's infrastructure (cloud resources, IAM policies, etc).

This configuration is used by a provisioning engine (e.g. Terraform, CloudFormation, Pulumi, etc.) during the deployment step to setup the infrastructure that is defined in them.

Since Wing code abstracts the cloud, you can choose the cloud provider and provisioning engine during compilation in order to generate configuration files that are specific to them.

You can see the compilation artifacts generated by compiling the code on the right to AWS and Terraform by checking out the **AWS/Terraform** tab below the editor.

Notice how the `cloud.Bucket` resource is implemented with an S3 Bucket.

Click on **"s3 bucket public access block"**. This configuration means that all public access to the bucket is blocked (we'll see how to change this later).

Now click on the **"s3 bucket server side encryption configuration"**. See that it has best-practice encryption configuration.

You can now switch to the **Simulator** tab and play with the bucket by uploading, downloading, deleting files, etc. To do that, click the **cloud.Bucket** resource and use the right-hand side panel to interact with it.

Click **NEXT** to see how to change the bucket's configuration.
