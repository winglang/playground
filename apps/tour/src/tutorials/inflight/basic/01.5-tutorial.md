# Preflight - Compilation artifacts

When compiling preflight code the Wing compiler produces configuration files that define the application's infrastructure (cloud resources, IAM policies, etc).

These files are given to a provisioning engine (e.g. Terraform, CloudFormation, Pulumi, etc.) during deployment to setup the infrastructure that is defined in them.

Since Wing code abstracts the cloud, you can choose the cloud provider and provisioning engine during compilation in order to generate configuration files that are specific to them.

You can see the compilation artifacts generated by compiling the previous step's code to AWS and Terraform by checking out the ***AWS/Terraform*** compilation target window below the Editor.

Notice how the `cloud.Bucket` resource is implemented with an S3. 

Click on the **"s3 bucket public access block"** to see that it blocks public access. We will talk about how to control this later.

If you click on the **"s3 bucket server side encryption configuration"** you can see that it has default encryption definitions. Other tutorials will explain how to change them.

You can now switch to the Simulator tab and play with the bucket (upload, download, delete files, etc) by clicking on the **cloud.Bucket** resource and using the right hand side panel to interact with it.

Click **NEXT** to see how to change the bucket's configuration.
