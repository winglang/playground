# Contract per phase - In practice

We will now see what having two different contracts for the same object in preflight and inflight code means in practice.

We will do it by creating a simple app that sets up a storage bucket with an event listener that prints the name and content of a file whenever it is created in the bucket.

#### preflight contract of the cloud.Bucket
First, let's define the event listener in the preflight phase, and explore the bucket's preflight contract in the process:

Type ***"bucket."*** in line 11 and see the available autocomplete options. Can you see that they make sense for the setup phase of the app?

Now, find the ***onCreate*** event listener in the options and add it to the bucket. 
This event listener will be called whenever one is added to the bucket.

The onCreate function has one parameter - an inflight function to run whenever a file is created in the bucket.

You can give it the ***onCreateHandler*** inflight function that is defined in line 5.
