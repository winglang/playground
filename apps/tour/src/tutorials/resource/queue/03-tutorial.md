# Publish to a topic

We can publish to a topic by calling the inflight `publish` method on it.

1. Uncomment the last three lines in the code editor.
2. Notice that a "Publisher" function was added to the Wing Simulator.
3. Click on the "Publisher" in the Wing Simulator and invoke it.
4. Notice the logs that are generated by the subscriber.
5. Now click on the AWS/TERRAFORM compilation output and explore the different assets and which permissions they are given.
