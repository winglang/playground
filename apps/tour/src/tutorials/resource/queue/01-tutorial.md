# Defining a Queue

The cloud.Queue class represents a data structure that holds a list of items. Using a queue, you can send, store, and receive messages between software components at any volume, without losing messages or requiring other services to be available.

1. Check out the AWS/Terraform compilation target window on the right.
2. The Queue is translated into an SQS Queue.
3. Click on the Wing Simulator compilation target (tab next to the AWS/Terraform one).
4. Click on the cloud.Queue
5. Can you spot the `Push` button on the right panel?
