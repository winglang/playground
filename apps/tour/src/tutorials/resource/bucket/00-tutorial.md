## Welcome to the Bucket tutorial

This tutorial is a straightforward walkthrough explaining `cloud.Bucket` and
its use cases.

We'll cover how to create a `cloud.Bucket`, examine the Terraform assets that
represent it, and use the inflight/preflight API to understand its
capabilities. Lastly, we'll create a simple application that stores copies of
the files uploaded to one bucket in another bucket.

This should be a fun learning experience. Click **START** to begin.
