# Multiple subscribers

A topic can have multiple subscribers.

The code in the editor has two subscribes that are added to the same topic. 
One converts the message to uppercase and the other to lowercase.
They both put the converted messages in a cloud.Bucket.

1. Play with the app in the simulator, start by invoking the "Publisher" and then check out the cloud.Bucket and the logs.
2. Click on the AWS/TERRAFORM compilation output and explore the different assets and which permissions they are given.
