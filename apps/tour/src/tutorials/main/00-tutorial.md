# Welcome to the Winglang Tutorial!

This is a step-by-step introductory guide to the Winglang language.

Wing combines infrastructure and runtime code into one language, enabling developers to stay in their creative flow, and to deliver better software, faster and more securely.

In order to understand the language, we're going to quickly build a smart queue that prints its messages and stores the latest one in a bucket.

To achieve the above, we will need a Queue, a Bucket, and a function that processes enqueued events prints them and stores each event in the bucket.

You'll interact with it in the embedded Wing Simulator, and then compile to AWS.
