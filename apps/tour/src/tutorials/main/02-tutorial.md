## Pushing a message to our queue

Let's start playing with our amazing cloud application with the Wing Simulator.

**Click** on the green node named **cloud.Queue**, and check out the panel on the right-hand side.
This is where you interact with the selected node.

Under the **Queue** fold, enter some creative message in the **Push Message** box.

Now, click the **Push** button.

🔍 Now, you should be able to see that the **Approx size** counter is now 1, because our queue now
has one message in it.

Ready to move on? In the next step you'll be introduced to fabulous `cloud.Function` resource.
