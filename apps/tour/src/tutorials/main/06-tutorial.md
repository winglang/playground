# Compile for Terraform

Once we finished building and testing our application in the Wing Simulator, we can compile it to
one of the supported targets so it can be deployed to the cloud.

Check out the tab labeled *AWS/TERRAFORM*, situated next to *SIMULATOR* on the right. This tab shows
the output of compiling our Wing program to Terraform on AWS.

Browse through the different Terraform resources that were generated by the code, and check out the
generated inflight JavaScript functions. 

This view will automatically update when the code is altered, so feel free to modify the code and
have some fun with it.

*🧑‍🎓 The compiler generates least privilege permissions. Look for the IAM Policy with the
`sqs:SendMessage` action.*
