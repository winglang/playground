# Compile for AWS

Congratulations! We've finished building and testing our application locally 🥳

Take note of a new tab labeled *AWS/TERRAFORM* on the right side, situated next to *SIMULATOR*. This tab presents the output of compiling the code to Terraform on AWS.

Feel free to browse through the different Terraform resources that were generated by the code, and observe the generated inflight JavaScript functions. 

This view will automatically update when the code is altered, so feel free to modify the code and have some fun with it.

*🧑‍🎓 The compiler generates least privilege permissions. Look for the IAM Policy with the `sqs:SendMessage` action.*
